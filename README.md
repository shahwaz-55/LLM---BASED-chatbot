# 🤖 ResumeRAG – AI Resume Chatbot

ResumeRAG is an AI-powered chatbot that allows users to upload their PDF resumes and ask questions about their skills, education, projects, and experience using Google Gemini.

## ✨ Features
- PDF Resume Upload
- Automatic Text Extraction
- Text Chunking
- Gemini Embeddings
- Semantic Similarity Search
- AI-Powered Question Answering
- Interview Preparation

## ⚙️ Installation

**1. Clone Repository**
```bash
git clone https://github.com/shahwaz-55/LLM---BASED-chatbot.git
cd LLM---BASED-chatbot
```

**2. Install Dependencies**
```bash
pip install streamlit numpy python-dotenv pypdf google-genai
```

**3. Configure API Key**

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
```

**4. Run Application**
```bash
streamlit run app.py
```

## 💬 Example Questions
- What are my technical skills?
- Explain my projects.
- Summarize my internship experience.
- Generate my self-introduction.
